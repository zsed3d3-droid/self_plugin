# Public packaging boundary

The original independent lab exercised Motion Canvas's actual native renderer. The public copy preserves its scene and player source, lockfile, asset-free HTML/CSS, fixed-frame checks and retained license texts. We do not copy private output PNGs, screenshots, raw runtime reports or the original data volume.

A separate Compose project and host8872 keep the original8862 lab running. The request Origin whitelist follows the public port so a public browser can save its own actual Stage PNG. Only the shared browser import and external additive evidence output paths change in verification code. Public evidence must be rerun and must not reuse original-source hashes as if public packaging had identical bytes.

No feature expansion is intended. Public runtime verification and persistence results are summarized in VERIFICATION.json. Native scenes/player internals are pinned3.17.2; an upgrade is a new compatibility task.
