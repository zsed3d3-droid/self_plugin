# Interaction lab attribution and publication boundary

This is a repackaging of the retained synthetic interaction experiment, with its UI, animation implementations, Next build configuration and third-party notice banner unchanged. Public-specific changes are the Compose project/host port, shared browser import, external verification-output directory and documentation. Its source tree is therefore not the original whole-tree hash.

Exact third-party license texts are retained under `licenses/` and served at `/third-party-notices.txt`. `package-provenance.json` records the exact npm tarballs, integrity, and observed license-file hashes. Next, React, React DOM, Tailwind, Motion and Anime package notices remain intact.

The built `animate.css@4.1.1` npm tarball contains the retained 2020 MIT notice. Current upstream commit `3f8ab233dbbd9d2fe577528d2296382954be3d1a` has Hippocratic 2.1; its separate license file is provenance and is not substituted for the built npm artifact's license. GSAP is not MIT. Its exact package notice and distribution header are retained, and the production build preserves that notice in shipped JS chunks. GSAP's linked current Standard No Charge License distinguishes ordinary web interfaces from competing visual animation builders; this fixed document-review fixture exposes no authoring/editor/builder capability.

No personal records, credentials, source sessions, screenshots, previous raw browser reports or runtime images are distributed here. Source-only publication does not publish the original live lab or its private evidence. Public build and task-check results, their limits and original-proof hashes are recorded separately in VERIFICATION.json.
