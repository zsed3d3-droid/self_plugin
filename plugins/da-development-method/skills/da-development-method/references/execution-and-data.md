# 실행·비용·DB 계약

프로젝트에서 실제 채택한 판단과 허가 범위를 연결해 적용한다. 공개 배포에는 개인 판단 원문이 포함되지 않는다.

## 넓은 도구와 좁은 행동 경계

도구를 사용할 수 있는 범위와 한 행동의 실행 권한을 별도로 기록한다. 원본 경로·산출물 경로·환경·외부 부수효과·과금 여부·사전 허가 범위를 실행 전에 결정한다. 원본은 컨테이너 read-only 마운트나 동등한 OS 경계로 보호하고 결과 디렉터리만 writable로 둔다. 허용 경로를 문자열로 적은 것만으로 격리가 완료됐다고 하지 않는다. symlink를 통한 출력 경로 탈출도 검사한다.

예: 원본 자료 검토→새 보고서 생성 요청이면 원본은 읽고, 지정 산출물 폴더에만 쓴다. 원본 수정 요청이 별도로 들어오면 그 행동의 쓰기 범위를 갱신한다. 기능별로 승인된 권한을 다른 프로젝트·주제로 자동 전용하지 않는다. 현재 개발 프로세스의 넓은 실행 모드는 과금·파괴·외부 발송의 동의가 아니다.

유료 도구는 현재 프로젝트/주제·목적·비용 범위에 해당하는 허가를 확인한다. 없으면 무료 대체 가능성을 검토한 후 필요한 경우 사용 직전에 사용자에게 묻는다. 저장된 카드와 인증 상태를 근거로 자동 결제/유료 생성하지 않는다. 유료 디자인 자산은 사용하지 않는 것이 사용자 기본값이다.

## API 입력과 오류 계약

기능 경계의 입력을 검증하고 같은 서비스의 HTTP 상태·오류 형식·복구 가능 여부를 일관되게 반환한다. 기존 계약을 재사용하며 문구만 바꿔 오류의 의미를 감추지 않는다. 잘못된 입력·권한 없음·동시 수정 충돌·결과 불명을 구별하고 현재 변경과 관련된 경로만 확인한다. 이 규칙이 모든 기존 API의 응답 형식을 재설계하라는 뜻은 아니다.

## 실서비스 PostgreSQL 기본값

신규 독립 실서비스는 최신 **안정 릴리스** PostgreSQL과 영속 볼륨을 사용한다. 개발 시작 시 공식 릴리스와 지원 상태를 확인해 버전을 명시적으로 고정한다. `latest` 태그나 RC/beta를 안정 버전으로 가정하지 않는다. 기존 공유 DB 정책이 있는 저장소에서는 그 마이그레이션/버전 계약을 사용하고 이 선호만으로 자동 메이저 업그레이드하지 않는다.

2026-10-28 확인 기준은 PostgreSQL 18.6이다. 19 RC1은 사전 릴리스이며 19의 정식 출시는 당시 11월 19일 예정으로 안내됐다. 이 날짜 이후에는 다시 확인한다.

- 안정 릴리스 원본: https://www.postgresql.org/docs/release/
- RC와 정식 출시 구분: https://www.postgresql.org/about/news/postgresql-19-rc-1-released-3409/

볼륨 선언뿐 아니라 실제 DB 데이터 경로와 연결됐는지 확인한다. 컨테이너 교체/재시작 후 기존 기록이 유지되는지 검증하고 덤프·복구 절차를 제공한다. 비밀값을 이미지/문서에 하드코딩하지 않는다.

SQLite는 명시적인 데모/시험용 예외다. 기존 `personal-workbench/review`는 사용자가 요청한 검토용 SQLite 데모이며 현재 판단 원본을 읽기 전용으로 추출한다. 실사용 Voice/My Work/Broker의 SQLite 초안은 PostgreSQL 전환 전 완성으로 표시하지 않는다. 이 계약은 DB의 실제 전환/배포를 완료했다는 뜻이 아니다.

## 제품과 반복 결과 보관

사용자의 연속 제품 루프에서는 완성품·진행품·실패한 반복도 유지한다. 첫 구현 및 다음 수정/재빌드 전에 소스와 현재 실행 이미지를 새 버전으로 고정하고 manifest에 해시와 적용 시점을 남긴다. 마지막 소스만 남기거나 이전 이미지의 태그를 재사용하지 않는다. 보관 실패는 다음 재빌드를 차단하는 이유이며 이전 산출물을 삭제해서 해결하지 않는다.

DB/업로드 영속 볼륨과 내보낸 결과를 유지하고 완료 시 비공개 DB 백업과 복구 안내를 추가한다. 소스 archive에서는 .env·인증 홈·개인 자격증명을 제외한다. 공개 카탈로그에는 안전한 선택 캡처와 요약만 둔다. 태그와 tar가 외부 매체의 백업이나 DB 복구 검증을 대신한다고 주장하지 않는다. 첫 상태의 보관을 놓쳤다면 가능한 근거와 누락을 명시한다.
