# 원천 검토와 실제 적용을 구분하는 계약

원문을 읽은 것, 스킬의 일부를 개발 흐름에 연결한 것, 라이브러리를 실제 실행한 것, 실제 제품에 적용한 것, 사용자에게 좋은 평가를 받은 것은 서로 다른 단계다. 설치 여부 하나로 이 단계들을 대신하지 않는다.

## 작업에 연결

- 기존 React·Next·Tailwind 프로젝트에서는 각 공식 문서를 연결한 `framework-profiles.md`를 읽는다. 세 기술의 공동 공식 skill 이름이 확인되지 않았다는 이유로 문서 기반 지식을 배제하지 않는다. React를 썼다고 Next·Tailwind나 모든 성능 규칙까지 적용한 것으로 세지 않는다.
- 모션은 현재 과업의 관계·상태·방향을 보여 주는 경우에 선택한다. CSS 기준판과 Motion, Anime.js, Animate.css, GSAP의 실제 API를 같은 과업에서 비교한다. 모든 의존성을 모든 제품에 넣는 규칙은 아니다. 입력·상태의 정확한 값은 보간하지 않는다.
- 설명 영상·도식은 Motion Canvas와 Remotion의 출력·프레임·문자 배치를 해당 과업으로 비교한다. 단순 웹 전환에 영상 엔진을 요구하지 않는다.
- Anti-slop과 Unslop UI는 디자인·개발 검수 skill이다. 의미 없는 중첩 표면, 장식 아이콘 타일, 불분명한 정보 위계, 오래 걸리는 일괄 등장, 확인하지 않은 성과 주장을 점검한다. 기존 사용자가 좋아한 구성과 실제 그룹·조작 경계는 보존한다.

## 제외할 강제 기본값

원천의 전체 mandatory 규칙을 전역 정책으로 복제하지 않는다. 고정 색상 비율·서체 금지·아이콘 금지·강제 생동감·밀도·모션 수치, 반복 모드 질문과 모든 작업의 장황한 보고 형식은 해당 사용자 요구를 대신하지 않는다. 필요 없는 래퍼를 없애다가 의미 그룹·선택 범위·발견 가능성을 잃으면 반례로 기록하고 복구한다.

## 필요한 기록

원천 URL과 revision, 읽은 파일, 라이선스, 선택한 규칙과 제외한 기본값, 적용 위치, 실제 소스·런타임 버전, 과업·입력, 전후 관찰과 캡처, 한계를 연결한다. 같은 브랜드의 최신 저장소와 예전 npm 배포본이 다르면 각각의 실제 소스와 라이선스를 따로 확인한다. 메타데이터의 라이선스 한 줄로 현재 원문과 패키지 내용을 대체하지 않는다.

도입 이유가 없으면 그 이유를 남긴다. 비교를 하지 않았다면 '불필요해서 검증 후 제외'로 표현하지 않고 '비교 미완료'로 표시한다. 검증 랩 통과는 제품 적용이나 사용자 채택의 증거가 아니다.

실제 Animate.css 실행본은 npm4.1.1의 MIT 라이선스이며, 위에서 조사한 현재 저장소의 Hippocratic2.1과 분리해 기록했다. GSAP는 실제 배포 청크의 원래 고지를 확인하고 누락을 수리했다. 메타데이터와 실제 배포물이 다를 수 있어 확인한 버전과 바이트를 남긴다.

결과/WHY/소스 해시는 `ux-lab/research/reference-gap-20261029/`의 interaction-outcome, anti-slop-freeze 및 Motion Canvas의 freeze에 연결한다. 실행 가능 공개본은 self_plugin의 `harness/reference-labs/`에 패키징하며 원본 실험과 배포본의 경로·포트 차이를 구분한다. 명시적인 검증이 호스트 Hook 자동 발화를 대신하지 않는다.

## 선별한 Anti-slop / Unslop 검수 기준

- 경계마다 소유권·선택·그룹 의미가 있는지 확인하고 반복 장식 래퍼만 줄인다. 서로 다른 작업공간을 같은 무경계 목록으로 뭉개는 것은 반례다.
- 아이콘 타일이 식별에 기여하지 않으면 덜어내되 사람·작업공간을 구별하는 표식과 조작 가능한 아이콘의 이름은 유지한다.
- 상태를 색만으로 구별하지 않고 이름·위치·문구로 읽을 수 있게 한다. 근거 없는 성과 수치나 측정하지 않은 효율 개선을 만들어 넣지 않는다.
- 같은 과업의 키보드 열기·초점 복귀·오류 복구와 좁은 화면을 확인한다. 전후 모양만 비교하고 동선을 확인하지 않은 결과는 완료가 아니다.
