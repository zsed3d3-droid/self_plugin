# Text Wireframe & Scenario Planner 2.0.0

사용자 과업의 진입→행동→결과와 필요한 예외를 텍스트 와이어프레임으로 연결합니다.
이미 제공된 요구는 다시 묻지 않고, 작은 수정은 바로 진행합니다. 구조적인 대안이 필요할 때만 비교하며 고정된 3안·Freeze Gate·반복 승인을 강제하지 않습니다.

와이어프레임의 영역 구분은 구현에서 중첩 카드를 만들라는 지시가 아닙니다. 여백과 정보 밀도는 과업·콘텐츠·기기에 맞춰 결정합니다.

[현재 지침](skills/text-wireframe-planner/SKILL.md). 기본 개발 흐름은 `da-development-method`이며 `scenario-ui-ux`로 구현과 실제 화면 검증을 이어갑니다.
