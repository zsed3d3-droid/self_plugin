# Unbox UI 1.5.0

중첩 카드·반복 네모를 점검하고 여백·정렬·타이포·목록으로 정보 구조를 개선하는 `$unbox-ui` 스킬입니다. 카드의 일괄 삭제나 데이터 중복 제거 도구가 아닙니다.

## 사용

DA Plugin Sets marketplace에서 `Unbox UI`를 선택해 설치한 환경에서 호출합니다. 실제 코드 변경은 수정 요청이 있을 때만 수행합니다.

```text
$unbox-ui 이 화면의 카드 안 카드 문제를 리뷰해줘. 파일은 바꾸지 말고
제거/유지 이유와 더 가벼운 대안을 알려줘.
```

```text
$unbox-ui 서비스 목록의 중첩 박스를 줄여줘.
기존 정보·실행 링크·권한 흐름은 유지하고 좁은 화면도 확인해줘.
```

```text
$unbox-ui 이 설정 화면을 박스 없는 그룹과 행 중심으로 구성해줘.
선택 상태, 입력 경계와 포커스는 명확하게 남겨줘.
```

## 판단 기준

- 정보 관계를 여백·정렬·타이포로 먼저 표현하고, 부족할 때 배경/구분선을 사용합니다.
- 독립 객체·선택 옵션·중요 CTA/경고 등 이유가 있는 카드는 유지합니다.
- 복합 뷰어(PDF/Canvas/차트)는 다중 카드 껍데기를 벗겨내 단일 기능 표면으로 평탄화하여 가용 폭을 확보하고, 상위 레이아웃 격리 방어(`min-width: 0`)를 점검합니다.
- 라벨마다 pill을 붙이거나 모든 배경/테두리를 일괄 제거하지 않습니다.
- 입력·선택·포커스·오류 상태, 접근성, 인증·기록 경로를 보존합니다.
- 복합 입력 래퍼(composer/검색바)는 내부 에디터의 불필요한 outline/border를 unbox하고, 외곽 `:focus-within`에서만 부드러운 단일 포커스 링을 유지해 이중 박스 결함을 방지합니다.

기존 `craft-ui-motion`의 스타일/모션 지침을 대체하지 않습니다. 필요한 구분선은 사용할 수 있으며 새 애니메이션을 추가하지 않습니다. 별도 상시 활성 규칙이나 새 런타임 의존성은 없습니다. 스킬을 로드하는 것만으로 외부 시스템에 쓰거나 배포하지 않습니다.

## 근거와 검증

[스킬 본문](skills/unbox-ui/SKILL.md), [사용자 자료 및 UI/UX 근거](skills/unbox-ui/references/sources.md)를 참고하세요. NN/g, GOV.UK, IBM Carbon, W3C의 원칙을 적용하되 특정 디자인 시스템의 외형을 강제하지 않습니다. 참고 스크린샷/HTML이나 외부 코드·이미지는 복제하지 않았습니다.

저장소 루트에서 패키지 연결을 확인합니다.

```sh
python3 plugins/unbox-ui/tests/test_package.py
```

패키지 검사는 manifest·marketplace·스킬 경로·로컬 참고 링크를 확인합니다. 에이전트 행동 시나리오는 루트 `evals/cases.md`의 UB 항목에서 별도로 평가합니다. 이 검사는 실제 앱의 시각 품질·접근성 적합성·호스트 설치 성공을 입증하지 않습니다.
